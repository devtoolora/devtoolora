# Changelog

All notable changes to Dev Toolora for VS Code are listed here. The project follows
[Semantic Versioning](https://semver.org/). The full changelog for the web app and the extension is
in the [repository](https://github.com/devtoolora/devtoolora/blob/main/CHANGELOG.md).

## 0.9.0 - Unreleased

The first public release, for VS Code, Cursor, Antigravity and other VS Code-compatible editors.

- More than 250 local developer tools in 18 categories. Input, selections and files never leave
  your computer, and the extension has no telemetry.
- Run tools on the selection from the context menu or the Command Palette, and replace the
  selection, insert at the cursor or open the result in a new editor.
- Sidebar catalog with favorites and recent tools; the panel follows your editor theme and reflows
  as you resize it.
