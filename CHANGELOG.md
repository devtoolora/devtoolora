# Changelog

All notable changes to Dev Toolora are listed here. The project follows
[Semantic Versioning](https://semver.org/).

## 0.9.0 - Unreleased

The first public release, as a public beta on the web and as an extension for VS Code, Cursor,
Antigravity and other VS Code-compatible editors. The desktop app follows in a later release.

### Tools

- More than 250 local developer tools in 18 categories, from JSON, YAML, XML and CSV formatting and
  conversion to encoders, hashes, keys and certificates, network calculators, CSS generators, image
  and PDF tools, and log and config helpers.
- Every tool runs on your device. Input, selections and files are never sent anywhere, and the web
  version works offline after the first visit. HEIC conversion and image OCR download their engine
  the first time you use them online.
- Every tool ships with samples, documentation and clear errors. Inputs that are ambiguous or out of
  range produce a warning or an error instead of a silently changed result.

### Web

- Searchable catalog with categories, favorites and shareable settings links that never include
  your input.
- Installable PWA with light and dark themes.

### VS Code extension

- Run tools on the selection from the context menu or the Command Palette, and replace the
  selection, insert at the cursor or open the result in a new editor.
- Sidebar catalog with favorites and recent tools; the panel follows your VS Code theme and reflows
  as you resize it.
